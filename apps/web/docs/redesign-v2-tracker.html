Nomad Poker Redesign v2 Tracker

Applying the Redesign v2 skin from the Screen Atlas to the web game in apps/web, on desktop (16:9) and phones (portrait only). Each screen is built, then checked by an independent agent against the atlas at both sizes.

Updated 13 Nov 2026 · phase 2 done: old UI replaced, one style, table HUD in v2 · checked by independent agents · typecheck, 219 tests and build pass · not committed

How it is built

  • New module src/ui2/: hand-built DOM screens with the v2 tokens (galaxy purple, Lilita One + Nunito, gold/blue/violet buttons). Layouts use flex and grid, not absolute positions, so one markup serves both orientations.
  • Hooked into the existing menu host: when the game asks the Unity menu to show a screen that v2 replaces, the v2 layer shows its own screen instead. Screens the atlas marks "Unchanged" (login, lucky slot, profile, wallet flows, chat…) keep today's look.
  • Same data and actions: every v2 screen calls the services the current screens use (account, wallet, retention, friends, tournaments, agents, web3, net). No new backend calls; the Shop is local only until a store backend exists.
  • Desktop: content scales with the window on an 80 × 45 em grid, like the atlas stage.
  • Phones: portrait layouts derived from v2 (stacked play tiles, the dock as a bottom tab bar, single-column panels, bottom sheets for dialogs). The store apps are locked to portrait, and a phone browser held sideways shows a "turn your phone" card.
  • Known gaps: the Shop has no purchase backend (buying says it opens soon); one agent per account, so New agent explains that; on-chain leaderboard shows "coming soon"; recently played friends and public tournament links need data that doesn't exist yet; the private SOL table was checked by rendering its parts, not live on devnet.
  • Checks: tsc --noEmit and vitest run stay green; each group is reviewed by a separate agent at 1280×720 and 390×844.
